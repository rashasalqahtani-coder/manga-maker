---
name: Legacy MangaDex access
description: Product decision for retiring MangaDex without breaking users' saved content.
---

Do not expose MangaDex as a source for discovering or adding new manga. Keep legacy reader, download, and library compatibility for items users already saved.

**Why:** The user chose a non-destructive retirement so existing saved manga remains readable.

**How to apply:** New screens and labels must not promote MangaDex or provide MangaDex search. Preserve legacy routing and data support unless the user later explicitly requests full deletion and accepts losing compatibility.
